Choose the guide that matches what you're trying to accomplish. Each page assumes you've completed the Quickstart, and throughout, keep two partnership ideas in mind: Coder governs **where** agents run, while OpenFlows governs **how** they coordinate.

```cards
- [Agent Setup](/docs/guides/agent-setup): Configure a team end to end: roles, models, skills, and tools through the agent registry.
- [Model Routing](/docs/guides/model-routing): Choose which model each role uses, from lightweight to rigorous - and switch live.
- [Multi-Tenancy](/docs/guides/multi-tenancy): Run several independent teams on one server with real isolation.
- [Extending: Skills](/docs/guides/extending-skills): Teach a role a new capability with configuration only - no system code.
- [Extending: MCP](/docs/guides/extending-mcp): Give the team access to a private tool, either per role or centrally.
- [Extending: Models](/docs/guides/extending-models): Add a new model to the platform catalog, configuration only.
- [Operations & Monitoring](/docs/guides/operations): See live status, steer the fleet (pause, drain, target, resume), and wire notifications.
- [Troubleshooting](/docs/guides/troubleshooting): What a stuck state means, symptom by symptom, and how to recover.
- [First Issue Walkthrough](/docs/getting-started/first-issue): Follow one issue from creation to a merged pull request. (Get Started)
- [Handling Escalations](/docs/concepts/human-escalation): Why you get pinged and how to resolve a ticket that needs you. (Core Concepts)
- [Extending with a New Role](/docs/concepts/agent-registry): The one extension that touches the system's internals. (See the Agent Registry)
```
