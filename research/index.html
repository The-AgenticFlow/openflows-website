    OpenFlows State Machine

    OpenFlows uses a durable state machine to control autonomous software delivery. The state machine defines how work moves from intent to merge, which approvals are required, which evidence is valid, and when downstream work must be invalidated. It is the coordination contract between agents, human reviewers, the shared store, GitHub, and the merge controller. The design goal is simple: autonomous agents may perform work, but only a versioned lifecycle record can authorize progress. Every phase transition must be explicit, evidence-backed, and recoverable.
