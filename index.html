How It Works

From GitHub issue to merged PR — fully autonomous. You focus on the vision, agents handle the execution.

1

Create an Issue

Describe what you want in GitHub. Natural language, no special formatting required. The agents understand context and intent.

2

Agents Work

NEXUS assigns tickets, FORGE writes code, SENTINEL reviews for security, VESSEL handles CI/CD, LORE documents everything.

3

Review the PR

Wake up to completed, tested, documented code. Review the PR, merge when ready. Only 8% of tasks need human clarification.

The 5-Agent Team

Each agent has a specialized role, working together like a human engineering team. They communicate, collaborate, and hand off work seamlessly.

👑

NEXUS

Orchestrator & Scrum Master

Plans sprints, assigns tickets, detects broken states, and ensures flow completion. The brain of the pipeline.

⚒️

FORGE

Senior Engineer & Builder

Writes code, tests, and opens PRs via Claude Code integration. Transforms tickets into working implementations.

🛡️

SENTINEL

Security Auditor & Reviewer

Reviews PRs for security, quality, and test coverage. The last line of defense before merge.

🚢

VESSEL

DevOps Engineer

Manages CI/CD, resolves conflicts, and squash-merges green PRs. Ensures deployment never breaks.

📚

LORE

Technical Writer

Writes ADRs, maintains changelogs, and preserves institutional memory. Documentation that stays current.
