Content Dashboard

Create and publish content that appears on the public website.

How to Publish Content

1

Open Tina CMS Studio

Click the "Open Tina Studio" button below to access the visual content editor

2

Create New Content

In Tina Studio, click "Create" and select your content type (Blog, Research, or Case Study)

3

Set Status to "Published"

In the content editor, change status to "Published" and click "Save"

4

Auto-Deploy

Tina auto-commits changes to GitHub - the site rebuilds and deploys automatically!

Tina CMS Studio
