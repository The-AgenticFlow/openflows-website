Getting Started

Get Openflows running in minutes. This guide walks you through installation, configuration, and your first autonomous workflow.

1. Prerequisites ▼
  • Rust 1.75+ — Install via rustup
  • GitHub account — With a personal access token (repo + workflow scopes)
  • LLM API key — OpenAI, Anthropic, or compatible provider
  • Git 2.40+ — For repository management
2. Install Openflows ▼
bash 
git clone https://github.com/The-AgenticFlow/Openflows.git
cd Openflows
cargo build --release

Or install from crates.io (coming soon):

bash 
cargo install openflows
3. Configure Environment ▼

Set the required environment variables:

bash 
export GITHUB_TOKEN="ghp_your_token_here"
export OPENAI_API_KEY="sk-your-key-here"
# Optional: Override default model
export OPENFLOWS_MODEL="gpt-4"
4. Run Your First Workflow ▼
bash 
# Start the Openflows daemon
openflows daemon start

# Assign a repository for autonomous monitoring
openflows repo add my-org/my-project

# Watch the agents work
openflows status
💡 Tip

NEXUS automatically discovers open issues, FORGE implements solutions, SENTINEL reviews the code, and the changes are merged as pull requests.

What Happens Next?

Once the daemon is running, Openflows will:

  1. NEXUS scans your repository for open issues and triages them by priority
  2. FORGE picks up assigned issues and writes implementation code
  3. SENTINEL reviews FORGE's pull requests for quality and correctness
  4. LORE maintains institutional knowledge across sessions
  5. Approved PRs are merged automatically (or held for your review)
