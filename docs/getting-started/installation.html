Installation

OpenFlows ships pre-built binaries for Linux and macOS. Choose the method that fits your workflow.

Install via npm

The easiest way to install on any platform with Node.js 18+.

bash 
# Install globally
npm install -g @the-agenticflow/openflows

# Verify
openflows --version

# Run the interactive setup wizard
openflows-setup

# Start the autonomous team
openflows

# Monitor workers in real-time
openflows-dashboard

# Diagnose environment issues
openflows-doctor
ℹ️ Prerequisites

Node.js 18+, Claude Code CLI (npm install -g @anthropic-ai/claude-code), and a GitHub PAT with repo + workflow scopes.

One-line installer

Downloads the correct pre-built binary for your OS and architecture, installs to ~/.local/bin.

bash 
curl -fsSL https://raw.githubusercontent.com/The-AgenticFlow/AgentFlow/main/scripts/install.sh | bash

After install, run openflows-setup to configure your environment.

Install via Cargo

Requires Rust 1.70+.

bash 
cargo install openflows
openflows-setup
openflows

Docker

Run OpenFlows in a container. Mounts your config directory for persistence.

bash 
docker run -it --rm \
  -v "$HOME/.agentflow:/home/openflows/.agentflow" \
  -e ANTHROPIC_API_KEY=your_key \
  -e GITHUB_PERSONAL_ACCESS_TOKEN=your_token \
  -e GITHUB_REPOSITORY=owner/repo \
  ghcr.io/the-agenticflow/openflows:latest

Or use Docker Compose with the LiteLLM proxy and Redis:

bash 
git clone https://github.com/The-AgenticFlow/AgentFlow.git
cd AgentFlow
cp .env.example .env  # fill in your keys
docker compose up

Build from Source

Requires Rust 1.70+ and Node.js 18+.

bash 
git clone https://github.com/The-AgenticFlow/AgentFlow.git
cd AgentFlow
make release        # builds all binaries
make install        # installs to ~/.local/bin
openflows-setup     # interactive setup wizard
openflows           # start the autonomous team

Required Environment Variables

bash 
# Minimum required — copy .env.example to .env and fill these in
GITHUB_REPOSITORY=owner/repo
GITHUB_PERSONAL_ACCESS_TOKEN=ghp_your_token_here
ANTHROPIC_API_KEY=sk-ant-your_key_here   # for Claude Code (FORGE agent)
DEFAULT_CLI=codex                         # or "claude"

Verify Installation

bash 
$ openflows --version
openflows 1.0.0

$ openflows-doctor
✓ Rust toolchain: 1.88.0
✓ Node.js: v20.11.0
✓ Claude Code CLI: installed
✓ Git: 2.44.0
✓ GitHub token: configured
✓ ANTHROPIC_API_KEY: set
✓ GITHUB_REPOSITORY: owner/repo
💡 Next Step

Run openflows-setup for the interactive TUI wizard — it guides you through all configuration options and writes your .env and registry.json files.
