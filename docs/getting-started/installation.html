Installation

Platform-specific installation instructions for Openflows. Choose your operating system below.

Install on Linux

Tested on Ubuntu 22.04+, Fedora 38+, and Arch Linux.

bash 
# Install Rust if not present
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env

# Clone and build Openflows
git clone https://github.com/The-AgenticFlow/Openflows.git
cd Openflows
cargo build --release

# The binary will be at target/release/openflows
sudo cp target/release/openflows /usr/local/bin/

# Verify installation
openflows --version
ℹ️ System Dependencies

On Debian/Ubuntu: sudo apt install build-essential pkg-config libssl-dev libgit2-dev

Install on macOS

Tested on macOS 14 (Sonoma) and macOS 15 (Sequoia).

bash 
# Install Rust if not present
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env

# Clone and build Openflows
git clone https://github.com/The-AgenticFlow/Openflows.git
cd Openflows
cargo build --release

# Copy binary to PATH
sudo cp target/release/openflows /usr/local/bin/

# Verify installation
openflows --version
ℹ️ Xcode CLI Tools

Run xcode-select --install if you haven't already. Required for the C compiler used by dependencies.

Install on Windows

Tested on Windows 10/11 with WSL2 and native MSVC.

Option A: WSL2 (Recommended)

bash 
# Inside WSL2 (Ubuntu)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env

git clone https://github.com/The-AgenticFlow/Openflows.git
cd Openflows
cargo build --release

Option B: Native Windows

powershell 
# Install Rust via rustup-init.exe from https://rustup.rs
# Use the MSVC toolchain (default)

git clone https://github.com/The-AgenticFlow/Openflows.git
cd Openflows
cargo build --release
⚠️ Windows Note

Native Windows support is experimental. WSL2 provides a more reliable experience. Some Git operations may require additional configuration.

Docker (All Platforms)

If you prefer containerized deployment:

bash 
docker pull ghcr.io/the-agenticflow/openflows:latest
docker run -d \
  -e GITHUB_TOKEN="ghp_your_token" \
  -e OPENAI_API_KEY="sk-your-key" \
  -v /path/to/config:/etc/openflows \
  ghcr.io/the-agenticflow/openflows:latest

Verify Installation

bash 
$ openflows --version
openflows 0.1.0

$ openflows doctor
✓ Rust toolchain: 1.77.0
✓ Git: 2.44.0
✓ GitHub token: configured
✓ LLM API key: configured
✓ Network connectivity: ok
