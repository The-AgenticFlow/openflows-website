Frequently Asked Questions

Common questions about Openflows answered. Can't find what you're looking for? Ask on GitHub Discussions.

What LLM providers does Openflows support? ▼

Openflows supports any OpenAI-compatible API, including OpenAI (GPT-4o, GPT-4, GPT-3.5), Anthropic (Claude 3 Opus/Sonnet/Haiku), and local models via Ollama or LM Studio. Configure the provider per-agent in openflows.toml.

Can I run Openflows on a private repository? ▼

Yes. Your GitHub token needs repo scope to access private repositories. Openflows treats private repos identically — it clones, reads, writes, and creates PRs the same way.

How does SENTINEL decide whether to approve or reject a PR? ▼

SENTINEL evaluates code on multiple dimensions: correctness (does it solve the task?), style (does it follow conventions?), security (any vulnerabilities?), and testing (are there adequate tests?). Each dimension produces a score; the overall score determines approve/request-changes/block.

What happens if FORGE writes buggy code? ▼

If SENTINEL catches the bug during review, it requests changes and FORGE gets another attempt. If a bug slips through and is merged, the next NEXUS scan cycle may discover it as a new issue. Review gates can be configured to require human approval for critical paths.

How much does Openflows cost to run? ▼

Openflows itself is free and open source. The main cost is LLM API usage. A typical task cycle (NEXUS triage + FORGE implementation + SENTINEL review) uses approximately 30,000–80,000 tokens, which costs $0.15–$1.20 per task depending on model choice. Using GPT-3.5-turbo for simpler agents can reduce costs significantly.

Can I run multiple FORGE workers in parallel? ▼

Yes. Configure multiple FORGE instances in openflows.toml. Each works on a separate task branch. NEXUS automatically distributes tasks across available workers. The default is 2 workers; you can scale up to match your LLM rate limits.

Is my code sent to third parties? ▼

Code context is sent only to the LLM provider you configure. If you use OpenAI or Anthropic, their API data policies apply. For maximum privacy, use a local model provider like Ollama — no data leaves your machine. Openflows itself does not send code to any third-party service.
