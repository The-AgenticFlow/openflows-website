API Endpoints

Openflows exposes a REST API on localhost:8080 (configurable) for programmatic control.

Agents

MethodEndpointDescription
GET/api/v1/agentsList all active agents and their status
GET/api/v1/agents/{id}Get details for a specific agent
POST/api/v1/agents/{id}/restartRestart a stuck or idle agent
DELETE/api/v1/agents/{id}Stop and remove an agent

Tasks

MethodEndpointDescription
GET/api/v1/tasksList all tasks with filter support
GET/api/v1/tasks/{id}Get task details and execution log
POST/api/v1/tasksCreate a new task manually
PUT/api/v1/tasks/{id}/assignAssign task to a specific agent
DELETE/api/v1/tasks/{id}Cancel a pending or in-progress task

Workflows

MethodEndpointDescription
GET/api/v1/workflowsList configured workflows
POST/api/v1/workflowsCreate a new workflow definition
PUT/api/v1/workflows/{id}Update workflow configuration
GET/api/v1/workflows/{id}/runsGet execution history for a workflow

Example Request

bash
curl -X GET http://localhost:8080/api/v1/agents \
  -H "Authorization: Bearer $OPENFLOWS_API_KEY" \
  -H "Content-Type: application/json"
json
{
  "agents": [
    {"id": "nexus", "role": "coordinator", "status": "active"},
    {"id": "forge-1", "role": "builder", "status": "working"},
    {"id": "sentinel", "role": "reviewer", "status": "idle"}
  ],
  "total": 3
}
