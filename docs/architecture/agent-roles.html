Agent Roles

Openflows uses five specialized agent roles, each designed for a distinct phase of the software development lifecycle.

NEXUS — Coordinator

The orchestrator. NEXUS reads incoming issues, evaluates their priority and scope, and assigns them to appropriate FORGE workers. It manages the overall workflow state and ensures no task falls through the cracks.

  • Triages new GitHub issues by labels, complexity, and dependencies
  • Creates task definitions with acceptance criteria
  • Assigns tasks to FORGE workers based on skill and capacity
  • Monitors workflow progress and re-assigns blocked tasks

FORGE — Builder

The implementer. FORGE writes code to solve assigned tasks. It reads the codebase, plans the implementation, writes the code, and opens pull requests for review.

  • Reads codebase context and task requirements
  • Plans implementation approach before writing code
  • Writes code following project conventions
  • Creates unit tests for new functionality
  • Opens pull requests with descriptive summaries

SENTINEL — Reviewer

The quality gate. SENTINEL reviews code for correctness, style, security, and test coverage. It can approve, request changes, or block PRs.

  • Reviews PRs for logic errors and edge cases
  • Checks coding style against project conventions
  • Identifies potential security vulnerabilities
  • Verifies test coverage for changed code
  • Produces structured review comments with line references

LORE — Historian

The memory keeper. LORE maintains institutional knowledge about the project's architecture, decisions, and patterns. It provides context to other agents to prevent repeated mistakes.

  • Records architectural decisions and rationale
  • Builds a searchable knowledge base from past sessions
  • Provides context summaries to FORGE and SENTINEL
  • Tracks recurring patterns and anti-patterns

VESSEL — Carrier

The infrastructure manager. VESSEL handles build, test, and deployment operations. It ensures the environment is set up correctly and runs CI pipelines.

  • Manages build environments and dependencies
  • Runs test suites and reports results
  • Handles deployment operations
  • Monitors resource usage and agent health
ℹ️ Configuration

Each agent's model, system prompt, and permissions are fully configurable. See the Agent Setup Guide for details.
