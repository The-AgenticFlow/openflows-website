Agent work your team can actually account for.

Trust boundaries

Give each runtime the authority it needs, not the keys to the platform.

The security model is defined by which system holds each credential and how a workspace proves its identity. We document these boundaries so your security team can inspect and test them.

Trusted control plane

Manager keeps platform authority

GitHub App signing material, the Coder operator credential, and the encryption key remain outside agent workspaces. Manager resolves organization, tenant, workspace, and repository scope on privileged requests.

Inspect the security model
Tenant execution plane

Workspaces receive limited access

A workspace registers with a one-time bootstrap, then uses a runtime session. GitHub installation tokens are short-lived and repository-scoped. Tenant Redis uses a tenant credential and namespace.

Inspect credential lifecycles
Recovery and audit

Work can be resumed and examined

Provisioning operations use database leases and idempotency keys. Tenant coordination records include assignments, heartbeats, hooks, and A2A evidence. Operators remain responsible for securing the supporting services.
